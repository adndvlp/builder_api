### Firebase CLI and Emulator Setup

1. Install Firebase CLI:
	npm install -g firebase-tools

2. Log in to Firebase CLI:
	firebase login

3. Enable webframeworks experiment:
	firebase experiments:enable webframeworks

4. Start Auth and Firestore emulators:
	firebase emulators:start --only auth,firestore

### Emulator Data Persistence

To save the current state of the data before stopping the emulator:
	firebase emulators:export ./emulator-backup

To start the emulator restoring the saved data:
	firebase emulators:start --import=./emulator-backup --only functions,auth,firestore,database
