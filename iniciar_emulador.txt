### Setup de Firebase CLI y Emuladores

1. Instalar Firebase CLI:
	npm install -g firebase-tools

2. Login en Firebase CLI:
	firebase login

3. Habilitar experimento webframeworks:
	firebase experiments:enable webframeworks

4. Iniciar emuladores de Auth y Firestore:
	firebase emulators:start --only auth,firestore

### Persistencia de datos del emulador

Para guardar el estado actual de los datos antes de detener el emulador:
	firebase emulators:export ./emulator-backup

Para iniciar el emulador restaurando los datos guardados:
	firebase emulators:start --import=./emulator-backup --only functions,auth,firestore,database
